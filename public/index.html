GitHub Contributions 3D

An animated 3D GIF of a GitHub contribution graph, regenerated daily by GitHub Actions

About

This visualization shows GitHub contribution activity as a 3D bar graph.

Each bar represents a day, with the height corresponding to the number of contributions.

The graph is automatically updated daily via GitHub Actions and published on GitHub Pages, so nothing is committed to the repository.
